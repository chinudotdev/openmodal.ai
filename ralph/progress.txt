## Codebase Patterns
- Schema files are in `src/db/schema/` and exported through `src/db/schema/index.ts`
- The new schema uses enums (e.g., `capabilityCategoryEnum`) instead of separate tables
- Build runs via `bun run build` which includes TypeScript checking
- Capability schema uses: `CapabilityCategory` type ("physical" | "cognitive" | "social" | "meta")
- Capability schema uses: `CapabilityStatus` type ("solved" | "partial" | "unsolved")
- Job schema uses: `JobCategory`, `RiskLevel`, `Confidence`, `Automatable`, `ImportanceLevel` types
- Job field renames: `title` → `name`, `automationStatus` → `riskLevel`, `industryId` → `category` enum
